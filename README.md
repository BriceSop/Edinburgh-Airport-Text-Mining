# Edinburgh Airport NLP Project
## *Description*
This project was carried out in partnership with the staff of the data department at Edinburgh airport, who wanted to highlight the main requests/points that customers mentioned, 
through a survey they conducted.
\
\
Initially, it was necessary to explore and pre-process the data, before being able to subsequently analyze these comments through three methods:
- Topic Modeling: it was a way to identify key topics, using three different techniques: TF-IDF with latent Dirichlet allocation, BERTopic, and a pre-trained Word2Vec combined with a K-means.
- Sentiment analysis: to estimate a satisfaction score regarding each comments.
- Frequency analysis: from the different topics, the goal was to represent the trends (positive, negative, etc.) that emerge from the comments on the recurring words.

With the results obtained, clear conclusions were submitted to the staff about the quality of the airport for customers.
\
\
There are two files, the notebook contains the different analysis and the script contains all the functions used in the notebook.
